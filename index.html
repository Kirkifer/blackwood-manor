Multiplayer Test Checklist

  1. Create a lobby as GM on your computer.
  2. Join from two separate phones or browsers using the code.
  3. Open the Public TV View in a separate tab/device.
  4. Start Exploration; confirm every device updates.
  5. On each phone, submit an adjacent move.
  6. On the GM screen, select Resolve Submitted Moves.
  7. Confirm the shared map expands, but only the individual phones reveal their own positions.
  8. Advance to Discussion and Haunt phases; confirm synchronized phase labels.
  9. Refresh a phone and check that it rejoins the same game with its own private journal.
